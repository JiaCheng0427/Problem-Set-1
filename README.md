# ECON 5200 Problem Set 1

The dashboard shows an 8.03% increase, but the true consumer average actually decreased by 1.13%.

The main problem is that large B2B orders and cancelled orders were included in Year 2. After removing orders above $500, the Year 2 average becomes 56.80, which is much closer to the true value of 56.15.

I think this correction is reasonable, but it is not perfect because some cancelled orders are still included. Before using this rule in a real dashboard, I would want to know whether any real consumer orders can be above $500.
